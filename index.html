Save Device Snapshot writes the whole profile to a snapshot file — trucks and their weights, every field with its acres, note and commodity, the loads with their weights and dry matter, storage locations, dry-matter history and archived summaries. The file is saved to this device and the share sheet opens so it can be sent to whoever is taking over.

Import Device Snapshot merges a snapshot someone has shared into this device. Nothing already here is erased, and loads that are already recorded are recognised and never entered twice, so the snapshot can be passed back and forth between operators. A load the snapshot still holds but this device has moved to the Trash is brought back out of the Trash rather than landing beside the copy already here. If the snapshot carries a dry matter reading this device has not seen, you are asked whether the loads already logged here should be moved onto it.

Save Current Field Snapshot is the same idea, scoped to just the field currently selected on the Loads page: that field's acres, note and commodity, every one of its loads in full detail, and the trucks and storage locations those loads used. Nothing else on this device is included. Bring it into another device with Import Device Snapshot above — it reads the same file format.
